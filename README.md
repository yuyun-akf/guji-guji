# 咕叽咕机 · GujiGuji

SillyTavern 第三方前端扩展，版本 **0.1.0（首个测试版）**。GitHub 仓库：<https://github.com/yuyun-akf/guji-guji>。

这是用于验证核心通信与存档的起步版本；代码已完成静态检查，但**尚未在你的 SillyDroid / Termux / SillyTavern 1.19.0 真机环境中验证**。请先备份需要测试的酒馆聊天存档。

## 本版可做什么

- 点击右下角 `☏` 打开一个独立的手机聊天窗，回复以消息气泡展示。
- 默认使用当前单人聊天里的角色设定；群聊暂不支持。
- 为当前角色的当前**聊天存档**保存独立手机消息。切换聊天存档时显示对应的手机记录。
- 可修改虚构手机故事时间；每条消息记录发送时的故事时间。
- 通过当前酒馆所连接的生成 API 发起独立生成，不把小手机消息插入正文 `chat` 数组。
- 显示简要错误状态；角色切换中已经发出的异步回复不会追加到切换后的存档。

## 还没有实现

- 角色定时或自主主动给用户发消息（下一阶段优先）。
- 进入后台后推送 Android 系统通知。
- 手机相册、发送真实图片、视觉识图。
- 正文与手机双向提取、检索、引用历史事件；当前手机聊天**不会自动进入正文提示词**，正文模型不会自动记得手机发生过的事。
- 自定义多个联系人、群聊、语音、朋友圈、完整手机桌面。
- 独立手机模型配置：暂时沿用当前 SillyTavern 的 API 与生成设置。

## 安装

### 通过 GitHub 仓库安装（将来推荐）

在酒馆的 `扩展 → 安装扩展 / Install Extension` 中输入仓库地址 `https://github.com/yuyun-akf/guji-guji`。仓库根目录直接包含 `manifest.json`、`index.js` 和 `style.css`，这是官方支持的第三方扩展安装方式。

**注意：本 ZIP 不是 Git 仓库地址，也不能把本地 ZIP 文件名直接粘贴进“安装扩展”的网址栏。** 还没上传仓库之前，请用下述本地方式测试，或者先把这些文件上传到你自己的仓库。

### 手动本地安装

1. 将本插件源文件放在一个独立文件夹中，例如 `guji-guji/`，文件夹内直接有 `manifest.json`、`index.js`、`style.css`。
2. 将文件夹复制到目标 SillyTavern 的扩展目录，如 `data/<user-handle>/extensions/guji-guji/`。实际用户目录取决于酒馆部署方式。
3. 重启或刷新 SillyTavern，启用扩展；进入一张单人角色卡的聊天存档。
4. 右下角出现 `☏` 后点击打开。

Android **SillyDroid 和 Termux 的文件位置与访问方式可能不同**。如果无法访问扩展目录，先不要改动系统文件，改走 GitHub 仓库安装更合适。

## 第一次测试清单

1. 打开普通单人角色卡，右下角出现 `☏`，打开/关闭不会遮挡原页面的基本操作。
2. 修改小手机故事时间，例如 `2021-09-01 20:00`，关闭后再打开时间不丢。
3. 发一条 `晚上好`，模型能回复；新消息只出现在手机里，正文聊天窗口没有多出任何楼层。
4. 刷新页面后，原手机消息仍在。
5. 切换到另一张角色卡，再切回：两边手机聊天互不混淆。
6. 切换到同角色的另一个聊天存档：手机记录也应分开。
7. API 不可用时出现提示，原文与其他插件没有被修改。

如果步骤 2–6 中任何一项失败，请保留报错截图和最短复现步骤，我们可以专门修改兼容层。

## 存档结构与边界

- 命名空间：`chatMetadata.st_little_phone_v1`。
- 本版不会读取或修改角色主聊天文本，也不会给角色偷偷注入额外正文记忆。
- 消息文本按纯文本显示（`textContent`），不会解释为 HTML。
- 手机历史目前在小手机生成时仅取最后 **24** 条作为上下文；完整消息仍在当前存档的手机记录中。长对话之后需要加入摘要/检索机制。
- 代码不包含 API Key，也不会请求独立第三方服务器；实际模型请求由 SillyTavern 当前生成接口处理。

## 兼容目标

- SillyTavern **1.19.0**。
- SillyDroid WebView / Termux 中的 SillyTavern 页面。
- 当前酒馆已配置的 OpenAI 兼容接口。

这些是**目标环境**，不是已经全部通过实机测试的认证；优先在用户的 SillyDroid 上验收，再逐步放开后续功能。

## 后续路线

1. **v0.2**：小手机打开且酒馆前台运行时，角色可以按条件主动发消息；增加开关、频率上限、防重复和防刷 API 请求。
2. **v0.3**：手机事件提炼与正文可控的双向记忆同步，尊重玩家编辑的时间线、不跨越尚未发生的故事日期。
3. **v0.4**：相册、真实图片发送、视觉模型识别；不支持视觉时提供手动描述并清楚标示来源。
4. 运行稳定后，再评估后台 Android 通知能力与 SillyDroid 适配。
