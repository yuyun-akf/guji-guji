# 🍡 咕叽咕机 · GujiGuji

SillyTavern / SillyDroid 虚拟手机扩展（**v0.4.2 测试版**）。

**安装或更新**：在酒馆扩展管理器中使用 `https://github.com/yuyun-akf/guji-guji`。打开方式：魔法棒 → 咕叽咕机。默认关闭悬浮入口。

## 功能

- **咕叽聊**：当前单人角色卡的独立手机聊天，一次点击「发送并生成」保存 user 消息并尝试生成角色回复。好友申请、删除、拉黑、撤销及重试。
- **运行日志**：记录发送、生成、保存和可捕获的异常。HTTP 502 等错误会提取响应状态码，并显示有限的 JavaScript 错误堆栈。日志不包含完整请求或 API Key。
- **设置**：API 可选「跟随酒馆当前连接」或「独立 OpenAI 兼容 API」。独立模式可输入 **Base URL（如 https://api.example.com/v1）、模型 ID、API 密钥**，使用 SillyTavern 1.19.0 的服务端完成请求，不会切换正文当前 API。URL / 模型与其他手机设置按聊天存档保存；**密钥只保留在当前页面内存，不写入聊天存档或导出设置，刷新后需要重新输入**。
- **条目选择**：预设及世界书不再使用设置页的小型滚动框。选择来源后点击「打开条目列表」，进入整页搜索、勾选并可展开全文的条目管理界面。独立勾选只影响小手机请求。
- **聊天回复**：默认使用贴近角色性格的即时通信风格，可输出多条独立聊天气泡。标点、口癖与消息长度随角色和情境变化，不统一固定。设置里可选择「自由文本，不自动拆分」。
- **日历**：设置当前角色当前聊天存档的手机故事时间。不同聊天存档可分别设置。
- **主题**：可上传不超过 750KB 的壁纸图片，调整字体，逐个替换桌面图标的文字/emoji。主题设置由酒馆扩展设置保存。
- **悬浮按钮**：可选，默认关闭；开启后在酒馆页面出现独立的 `☏`。
- **相册 / 购物 / 外卖**：保留桌面入口，目前尚未实现业务功能。

## 当前限制

- 独立 API 当前支持 **OpenAI Chat Completions 兼容接口**。部分接口对 URL / 参数或鉴权的实现不完全一致，需以实际发送正常手机消息为准。独立 API 密钥刷新后需要重新输入。预设的**单条文本**注入不等同于整套预设的采样、排序、变量解析和完整编排。
- 选中世界书条目后，将对应文本直接加入手机生成提示词；目前不会运行全部世界书触发条件、深度排序或复杂宏。此功能优先适配酒馆 Chat Completion 预设。
- 正文与手机历史尚未双向同步；相册图片发送、视觉识别、角色主动发消息、后台通知尚未实现。
- SillyTavern 1.19.0 / SillyDroid 为兼容目标；v0.4.2 更新需要继续实机验证。原先出现的 `Got response status 502` 属于生成请求故障状态，此次增加了**连接测试和更详细的日志**，但不能保证已消除上游 502。
- 目前只记录本扩展能够捕获的报错，不是全部服务器控制台日志。

## 排查

1. 更新后确认扩展版本是 **0.4.2**，刷新酒馆，魔法棒 → 咕叽咕机。
2. 打开「设置」→发送正常手机消息。通过说明简单的独立生成可执行，不代表完整角色提示词一定成功。
3. 打开「咕叽聊」→「重新生成上一条回复」，或发送新消息；失败后去「运行日志」查看请求阶段、错误码和简短堆栈。
4. 测试「悬浮按钮」开关。它与魔法棒入口共用同一个手机界面。
5. 检查「日历」按不同存档保存的时间，以及「主题」切换后的显示效果。

## 数据

手机消息、好友状态、故事时间和已选条目保存在当前聊天 `chatMetadata.st_little_phone_v1`；兼容旧版该命名空间。主题与可选悬浮按钮放在 `extensionSettings.gujiguji` 下。插件不会直接修改正文聊天消息。
## v0.4.2

API 设置只保留「保存 API 配置」按钮。保存只验证地址格式与必填项并写入当前聊天存档配置，**不会向模型发送额外测试请求**。连接是否正常，通过咕叽聊发送真实消息验证；失败可查看运行日志。刷新页面后独立 API 密钥需要重新输入。
