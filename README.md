# 🍡 咕叽咕机 · GujiGuji

SillyTavern 1.19.0 / SillyDroid 虚拟手机插件，**v0.5.0 测试版**。

安装与更新：`https://github.com/yuyun-akf/guji-guji`。酒馆魔法棒 →「咕叽咕机」。悬浮入口可选，默认关闭。

## v0.5.0：咕叽聊界面重构

- **消息首页**：点击桌面「咕叽聊」先进入消息列表，不再直接打开聊天框。
- **通讯录**：消息 / 通讯录底部切换；「新的朋友」查看当前角色的待处理好友申请；点联系人头像与姓名进入资料。
- **好友资料**：可添加好友、重试/撤回申请、处理收到的申请、删除好友、拉黑和解除拉黑。可按已有剧情设定初始好友关系。旧数据保持兼容。
- **头像**：聊天气泡双方显示头像，角色默认读取当前酒馆角色卡头像，用户默认尝试读取当前人设/聊天记录中的用户头像；可在资料页分别上传自定义头像（不超过 350KB）或恢复默认。若无法找到人设头像则使用酒馆默认图标。
- **聊天页**：移除占据上方空间的好友管理与重复状态提示，仅保留消息气泡中的「正在输入」提示。输入框与发送按钮合并为紧凑的一行，使用移动端 visualViewport 尝试在键盘弹出时压缩弹窗高度。
- **聊天记录管理**：右上角「···」菜单可以导出 JSON、复制 JSON、导入 JSON、清空消息或删除当前会话。导入替换当前存档的手机消息，不覆盖独立 API、预设、世界书、日历和好友关系。两种删除操作都需要确认；删除会话后可从通讯录重新开始。聊天消息旁「⋯」可删除单条，部分 Android 设备也可长按气泡。
- **消息数据**继续保存在 `chatMetadata.st_little_phone_v1`，旧版本中的消息不会因本次界面更新自动删除。

## 其他功能

- 独立 OpenAI 兼容 API 配置：可使用酒馆当前连接，或设置独立 URL、模型 ID、临时内存密钥。保存不额外发送测试请求，正常聊天时才调用 API。独立密钥在刷新后需要重新输入。
- 预设和世界书支持分别选择单个文本条目，使用独立的可滚动、可搜索条目页；不会改变正文开启的预设和世界书条目。
- 日历按当前角色和聊天存档独立保存故事时间；主题支持壁纸、字体和桌面图标调整。
- 保留运行日志与生成失败重试，独立生成不会把手机消息直接插入酒馆正文。
- 当前聊天模型可按角色性格输出口语消息，连续回复可以拆成多个气泡；也可关闭自动拆分。

## 当前限制

1. 通讯录目前以**当前酒馆角色及当前聊天存档**为范围，不是跨所有角色卡的统一好友数据库；不同角色同时在线、跨角色转发与群聊还未开发。
2. 手机与酒馆正文的双向记忆同步、角色主动消息、相册识图、购物、外卖尚未实现。
3. Android / SillyDroid 上 JSON 下载、虚拟键盘视口、头像读取依赖具体客户端的 WebView。复制 JSON 是下载的备用方式。
4. 独立 API 仅面向兼容 OpenAI Chat Completions 的服务。UI 静态与逻辑检查不等于实机验收；更新后需测试。

## 推荐测试

更新到 v0.5.0 后刷新酒馆：

1. 桌面 → 咕叽聊 → **消息列表**；底部切到**通讯录**，点角色看资料，再进聊天。
2. 确认角色及玩家头像是否读取成功；如果没有人设头像，可在资料页上传并测试恢复默认。
3. 发送消息时只出现一个输入中气泡；打开键盘后能正常查看消息并发送。
4. 长按或点气泡旁 ⋯ 删除单条；聊天右上角 ··· 导出 JSON，清空后导入，确认消息恢复。
5. 更换聊天存档，确认以前的数据不混淆。

仓库代码仍保留旧数据存储键；如需保留聊天内容，请在首次清空前导出备份。
