# 🍡 咕叽咕机 · GujiGuji

SillyTavern **1.18 / 1.19** 虚拟手机扩展，当前 **v0.17.0 测试版**。入口：酒馆魔法棒或扩展设置 →「咕叽咕机」。悬浮按钮可选、默认关闭。

安装与更新：https://github.com/yuyun-akf/guji-guji



## v0.17.0 — 全机统一交互反馈

- 九个桌面应用共用按钮按下缩小与松开回弹（包含动态生成的列表、导航和操作按钮）。
- 从桌面应用图标进入时，由图标位置展开至手机页面；返回桌面时反向收起。其他内页切换使用轻量过渡。不支持 Web Animations API 时会正常降级。
- 统一提供操作中、成功、错误三类状态反馈；群星和外卖异步操作已接入；锁屏密码、头像、贴纸、资料与设置原有状态文字也会同步反馈。
- 主题页新增全局动画强度：关闭／柔和／标准（默认标准）。尊重系统减少动态效果，关闭动画不影响文字提示。
- 外卖数量增减保留滚动位置，不再每次自动返回顶部。
- Android WebView 的实际动画和触摸效果仍需实机验收。

## v0.16.0 — 配色、群星与锁屏修订

- **锁屏键盘**：三列数字键的水平间距左右对称收紧，纵向行距和按键尺寸不变。
- **内置配色**：新增「鸢尾流光」「海棠春信」「金盏朝露」三套植物命名的六色内置主题，沿用现有 SVG 图标和页面造型，只替换 UI 配色；覆盖图标、聊天及引用气泡、红包与转账各状态。四套内置主题的名称统一显示为「植物名（内置）」，自定义主题与原有数据继续保留。
- **魔法棒**：修正咕叽咕机在扩展菜单里文字被浅色图标染淡的问题；分别继承其他插件的文字与图标实际颜色。
- **群星**：每次打开重新请求推荐流；旧互动记录不再插回推荐首页。在「我 → 我的互动」及「我 → 群星设置」可确认清空本存档测试互动，保留原创动态和角色账号。转发同步「我的动态」；取消转发时同步移除。
- **相伴天数**：桌面时间栏显示「与角色名相伴 N 天」，首日计 1 天，以当前存档最早有时间的聊天消息为起始，跟随剧情时钟自动更新。
- **验收**：逻辑模拟已完成；Android WebView 的实际布局及第三方酒馆美化兼容需实机验证。

## v0.15.0 — 稳定翻页、统一返回与可导入的主题库

- **桌面翻页**：停用在 Android 上露出隔壁页面内容的 3D 立方体、卡片叠加特效，保留平滑滑动和淡入淡出。旧存档选择失效效果时自动回退平滑滑动；过渡结束后非活动页面不可见、不可点击。
- **顶部返回**：群星帖子详情、热搜详情、我的设置等二级页面只用手机固定的左上角返回，取消滚动内容中会消失的重复返回按钮；外卖商户、地址、订单也采用逐层返回。
- **外观图标**：吱付宝四个菱形不再被 SVG 边界裁剪，设置图标重绘为同心正圆齿轮；魔法棒入口主动读取同菜单其他扩展图标的计算颜色，尽量跟随酒馆当前美化。
- **可命名主题库**：自定义主题可以命名、另存、重命名、删除、导入/导出 JSON，最多 20 套；四套内置主题直接提供，且与自定义主题分开管理。主题独立记录颜色、壁纸、字体、应用图标、悬浮按钮图标、桌面及聊天样式。
- **导入美化资源**：主题页支持字体 TTF/OTF/WOFF/WOFF2（≤400 KB）、应用及悬浮按钮 PNG/JPEG/WebP 图片（≤400 KB），以及经过检查、作用域严格限定在 #st-little-phone-root 的普通 CSS（≤40 KB）。完整主题 JSON ≤2 MB。导入 CSS 不允许 @ 指令、外部 URL 或修改酒馆宿主页面。
- **可视化编辑**：提供桌面图标尺寸、行距、聊天气泡圆角设置，并增加可复制的常用 CSS 类名指南。每套命名主题的壁纸独立绑定；切换默认主题不会继承自定义 CSS/字体/图标。
- **外置恢复保留**：遇到损坏美化可从酒馆扩展设置直接「恢复默认主题」，不会删除其他已保存主题或聊天；密码重置仍为独立功能。
- **限制**：目前不支持可拖拽的任意桌面坐标布局、复杂 CSS @media 动画、SVG 图标文件或嵌入式全页面多场景预览。样式及 WebView 手感仍需 Android 实机验收。

## v0.14.0 — 外卖测试版与外置恢复

- **外卖应用解锁**：桌面外卖不再灰显。三个底部导航：浏览（虚构商户与菜单、剧情周边商户生成）、购物车（按商户分组、数量加减、分别结算）、我（我的订单、收货地址、账号资料）。提供四家明确标为剧情示例的初始店铺；不读取设备 GPS、不创建真实外卖订单、不显示未经证实的真实商户评分和营业状态。
- **订单与吱付宝共用账本**：结算必须有收货地址和足额余额，订单记录当前剧情时间、商品与收货地址快照；付款通过预留的 walletChargeOrder，仅成功写入存档才保留扣款；未接单订单可从订单页取消并经 walletRefundOrder 退回余额，不会产生重复资金流水。
- **剧情商户生成**：浏览页主动点击时才调用一次模型，生成虚构的店铺及菜单。生成失败不清空原有商户；存在购物车商品或订单的店铺继续保留。剧情地点只使用文本中已经明确标记的地点，不读取用户设备位置。
- **酒馆扩展设置**：新增唯一的外置「恢复默认主题」与「重置小手机密码」入口，作为美化失效和忘记密码时的恢复机制。恢复主题切回默认的内置琉璃繁缕，不清除聊天、其他已保存的主题资料或业务数据；密码重置只删除锁屏设置，需确认，下一次进入重新设置密码。无须再增加同义的“禁用美化安全启动”按钮。
- **主题库后续扩展约束**：内置主题作为预设保留；其他自定义主题在主题库实现后应支持独立删除。当前版本尚未提供多主题删除/导入/导出管理器，也未实现新的成人直播 App。
- **验收**：已进行源码语法与模拟支付/退款检查；Android 酒馆 UI 与真实模型生成仍需设备测试。升级时勿卸载或清空故事存档。

- **桌面翻页**：四种动画统一使用等高的完整桌面页面，不再在切页时突然移除上方组件。时间卡片和热搜框属于第一页，会跟随第一页一起移出；后续页面应用从顶部开始。日常剧情／时钟更新不会反复重建图标，降低动画被打断的概率。
- **群星「我」**：个人资料下方五个入口改为逐行菜单，进入后显示独立子页面及返回键。头像选择改为显眼的大面积预览控件；安卓相册取消、返回事件受到保护，不应直接关闭咕叽咕机。

- **主题**：所有应用的滚动条使用同一套蓝灰色，输入框滚动条保持隐藏。主题页面新增「将壁纸绑定当前主题」，开启后琉璃繁缕与自定义主题分别保存各自的壁纸，切换主题自动切换桌面和锁屏壁纸。现有上传壁纸在绑定前继续沿用原有共享方式。

- **吱付宝**：移除与账单重复且混入社交动态的「事件记录」显示栏目，保留底层手机与正文事件通道。账单和待处理交易显示收付款对象，备注与对方姓名分开呈现；新交易保存对方当时的名称快照，旧交易根据联系人关系尽量恢复姓名。不清理原有账本。
- **验证**：已进行源码语法、页面节点、时间和账务模拟校验；实际 Android 酒馆 UI 与真实模型调用仍需设备验收。不要通过卸载扩展或清空聊天数据进行更新排查。

## 更新到 0.11.0（群星与桌面优化）

酒馆扩展管理器更新后刷新酒馆页面，确认版本 0.11.0。**不要卸载扩展或清理原有聊天存档**。

- **主题**：第一套可选主题为「琉璃繁缕」，严格使用六色色卡（白、浅蓝灰、浅粉、玫瑰粉、灰蓝、深蓝）。支持玩家自定义六个色值、字体与本地图片壁纸；图片会缩放压缩后保存，立即应用于**主页、锁屏**。如旧 CSS 仍显示纯色，请强制刷新资源。桌面图标下移、移除白色方块底和固定底栏，应用排序改到「主题」。原微博更名「群星」，图标为四角星；时间卡片下的按钮改为群星热搜入口。
- **锁屏**：使用六位显示点与数字键盘输入，密码长度为 4～6 位。新用户先输入再确认，已有密码继续验证；「设置 → 修改解锁密码」可输入旧密码、两次新密码保存。
- **群星**：底部「首页／发现／周边／发布／我」五栏。首页是世界推荐信息流，发现显示世界热搜，周边使用故事环境生成动态与附近热门话题，发布是玩家主动发帖，我页面含昵称、ID、头像、简介、粉丝和关注列表。
- **手动账号管理**：「群星 → 我 → 群星设置」可以添加和编辑角色／NPC／媒体／粉丝账号，设置头像、昵称、ID、职业简介、公众人物标记和粉丝数。作者未预设账号也能使用。关注随机网友会把该账号固定，取消关注不会自动删除账号资料。原版微博已互动的帖子仍可浏览；新的互动记录、玩家帖子、已关注账号的帖子及账号关系持久化到当前剧情存档。
- **角色自主营业**：「我 → 群星设置」单独开启，默认关闭。根据剧情时间间隔检测已手动建立的角色账号是否需要发公开动态，角色可输出 \`[SKIP]\` 不发。每次生成会消耗 API 调用；不代替玩家发布，不把私聊秘密自动曝光。可点击「测试角色自主发布」立即试运行。仅在酒馆页面活动并已打开过群星模块后运行，非系统级后台任务。
- **兼容性**：旧存档聊天、吱付宝账本、朋友圈、联系人保持原状，群星数据独立保存。动态生成质量仍取决于当前模型与已提供的角色设定。更新完成后建议实机核对壁纸持久化、键盘、发帖和角色账号头像上传。

## 更新到 0.10.0

在酒馆扩展管理器更新本扩展，完成后刷新页面。确认扩展版本和手机桌面显示 0.10.0；仍显示旧版时重新加载页面。不要卸载、清空浏览器数据或删除聊天来排查入口问题。

0.10.0：**六色主题、单色图标、锁屏、可滑动桌面、故事时钟与微博首版。** 使用瑞士纸币色卡的六色搭配：#ffffff / #e0e8f2 / #f1d6d6 / #e39f9f / #8b9bc1 / #35568a；无绘画背景，图标都以统一蓝色单色造型呈现。微博是报纸，运行日志是警示三角形。未开发应用灰显，不显示状态标签。

开启手机后先进入锁屏，首次须设定 4～6 位密码，然后解锁进入桌面；在设置可关闭锁屏。桌面支持左右滑动分页，在设置中通过上移／下移保存应用排序。时间可设置成「与现实同步，关闭继续流动」「只打开小手机时流动」「自定义流速并选择关闭时是否继续」，聊天不再每发送一条自动虚增一分钟。手动日历与快捷跳时依旧可用。天气／地点仅在剧情文本明确出现「当前地点：…」「当前天气：…」或已有明确状态时才展示，不读取现实定位。

转账／红包在待领取时统一玫瑰红，已领取／过期后转蓝灰色；不区分双方颜色，不再提供手动撤回，依旧按 24 剧情小时未领退回。卡片直接显示在聊天区域，没有外层紫色气泡。

「微博」已替换相册：进入后自动请求生成至少 10 条帖子，手动刷新再次请求 10 条，每条至少 5 条评论；有混合领域热搜、查看完整评论、点赞、评论、收藏、转发、发布微博等操作。「我的互动」只保存你实际参与过的帖子；刷新时其他旧帖丢弃。为降低截断风险，10 条分两批各 5 条生成，生成失败会提示报错，不会虚构补齐。后续可继续完善模型对热点的持续跟踪和评论互动。

0.9.0：**吱付宝及正文双向联动首版。** 吱付宝现在有真实可操作的余额、手动设定、账单、待处理转账与红包；从手机聊天的「＋」→「转账／红包」填写金额和备注即可发送。余额不足不能支付。收到转账或红包后必须由 user 明确点击「收款」才增加账户余额；可拒收。已经发出的款项可撤回，故事时间超过 24 小时仍无人收款则退款。角色发出的转账和红包也有可点开的实际交易卡片。

**正文联动**：当角色在 SillyTavern 正文明确说出「我已经给你转了200元」等已完成的动作时，手机会自动创建待收款交易；「我想转」「准备转」不会触发。正文改掉原支付剧情时，会取消对应交易并尝试冲正。手机里的收款、拒收和好友变更，会以结构化的事件事实提供给正文模型，不用再复制粘贴聊天；它们不能替 user 自动收款。可在手机设置中关闭事件联动。复杂的非标准用语不保证识别；切换正文时间到手机过去模式时，事件联动会暂停。

## 当前功能

- **四栏导航**：消息、通讯录、发现、我。「新的朋友」只展示收到或发出的申请；通讯录只显示好友。添加页可以继续查看未添加人物。
- **统一添加入口**：通讯录 → 添加好友／故事人物，选择手动创建或扫描角色设定／世界书。扫描候选须逐个核对、勾选、确认，不直接变成好友。
- **人物扫描**：默认只读取当前角色卡、角色内嵌/绑定世界书、当前 user 人设及其绑定世界书。其他世界书须明确手选；不再扫描全部可用世界书，也不因手机预设选用了文风书就将它加入扫描。跳过禁用条目，排除当前 user 名称和人设里明确填写的别名，以及文风/写作规则条目。{{user}} 设定中的已命名朋友仍可识别。每本最多280条；规则扫描仍可能误判或漏判，请核对候选。旧版本已保存的人物不会被自动删除。
- **关系门槛**：新故事默认非好友。扫描人物须有正文交换联系方式线索或玩家手动确认，才能申请；手动创建人物允许主动申请。旧关系保留。当前可根据正文明确提及的发起人和申请事件产生收到的好友申请；模糊否定、代词和第三人叙述仍需人工核对。
- **图片表情包**：安装后库为空，不附带任何图片、不自动读取外部仓库。可在「我」上传 PNG/JPG/WebP/GIF，或批量导入 ZIP／JSON／图片＋CSV；`表情包目录.csv` 的「内容」「用途」自动成为标签，名称也可手动修改。聊天图片可「收藏为表情包」。同一酒馆账号下跨角色/存档共用，user 点图发送，char 根据标签选择库中图片；表情包不强制视觉 API。每张350KB以内，最多100张、图片总数据约3MB；已发送的表情包不会因删除图库条目而丢失。
- **聊天工具**：图片、引用及消息操作。电话、转账、定位填写剧情通话邀请、虚拟金额、故事地点，不是实际电话、支付或定位。普通照片可交由酒馆当前支持视觉的模型直接读取，无需独立 API；也保留可选的独立 API 模式。表情包不受视觉能力限制。图片和表情包 JSON 备份保留载荷。
- **朋友圈**：「发现」发表当前玩家的文字或单张图片动态，保存于当前故事；点赞、评论、回复与转发本身不调用模型。若开启默认关闭的自动互动，同条新动态的最多四名有权观看的角色合并为一次模型请求；你后续发表评论需要角色回复时，额外按批次调用一次。角色/NPC 自主发帖与其初始互动合并请求。角色之间互动必须明确互有联系方式；没有群聊。
- **独立私聊**：当前角色与每位 NPC 分开保存消息和关系，按当前角色的当前正文聊天存档隔离。
- **设置与主题**：酒馆当前连接或独立 OpenAI 兼容接口、多世界书按需激活、只读正文记忆、可关闭的手机记录影响正文、头像、壁纸、字体、图标、故事日历。独立 API 密钥仅在内存，刷新后重新填写。
- **备份与诊断**：聊天 JSON 导出/复制/导入、删除单条、清空会话、运行日志。导入替换当前联系人的手机消息，先保存备份。

## 旧聊天保护

存储键仍为 `chatMetadata.st_little_phone_v1`，数据版本仍为 1。升级、启动、启用/禁用不会清空聊天，不迁移存储键。旧消息、消息 ID、自定义字段及主角色/NPC 独立对话保持兼容；没有 friendship 字段的旧聊天保留好友状态，新故事才默认陌生人。

可在更新前导出重要手机对话和酒馆正文存档。删除 NPC、清空/删除聊天及导入替换是玩家主动操作，不属于升级过程。
